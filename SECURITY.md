# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, please use one of the following:

1. Open a **private security advisory** on GitHub (preferred).
2. Contact the maintainers directly.

We will acknowledge receipt within **48 hours** and aim to provide a status update or fix timeline for critical issues as quickly as possible.

## Scope

SkillGuard is itself a security scanner. We also welcome reports of:

- False negatives (real threats that the current rules miss)
- Ways to bypass existing detectors
- Issues in the scanner’s own code that could affect users

Thank you for helping keep Agent Skills safer.
